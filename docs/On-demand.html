Running RStudio on Hyak using On-Demand feature

Pro at RStudio but would benefit from more resources? It is easier than ever to launch a RStudio Instance on Hyak.

Note

see also: https://hyak.uw.edu/docs/ood/start

1 Access Dashboard

Go to https://ondemand.hyak.uw.edu/pun/sys/dashboard/

Click on Interactive Apps

2 Selecting Resources

Decide on what specific resources are available and needed.

You will be then be asked for information on resources you will ask for.

If you this is the first experience with Klone you it might be good to get familar with what resources are available to you.

For this you can login to Klone at command line from this webpage by clicking on >_Klone Login and entering your credentials. From there you can run command hyakalloc to see what resources you have access to.

2.2 Leveraging ckpt as resource

If you only need instance running < 5 hours one might say best practices would be to use ckpt. ckpt are unused resources by larger UW community thus not using your own group shared resources. However you will get kicked off at around 5 hours.
