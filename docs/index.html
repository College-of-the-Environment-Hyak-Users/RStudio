Running RStudio on Hyak using On-Demand Feature

Note

If you’re experienced with RStudio but new to Hyak, launching an instance via the OnDemand portal is easier than ever.

See also: Hyak OnDemand Docs

1 Accessing the Dashboard

Go to the OnDemand Dashboard:
https://ondemand.hyak.uw.edu/pun/sys/dashboard/

Click on Interactive Apps:

2 Selecting Resources

After selecting RStudio, you’ll be prompted to specify the computing resources needed.

If you’re unfamiliar with the Klone cluster, it’s helpful to explore your resource allocations:

  1. Click on >_ Klone Login from the dashboard.
  2. Enter your UW credentials.
  3. Run the hyakalloc command:
hyakalloc

This will display your available and used CPU/memory allocations.

Based on your allocations, select an appropriate partition and number of cores:

2.1 Using a Custom Container

A key benefit of OnDemand is the ability to launch custom container environments.

If you’re working with genomics or bioinformatics, consider using:

/gscratch/srlab/containers/srlab-R4.4-bioinformatics-container-a83e518.sif

This container includes:

Program Version Install Method Notes
Apptainer 1.4.0 .deb package Required for Nextflow/nf-core support
Bismark 0.24.2 Source Requires Bowtie2
Bowtie2 2.5.4 Binary
DIAMOND 2.1.9 Binary
FastQC 0.12.1 Binary Renamed fastqc-${version}
HISAT2 2.2.1 Source Compiled with make
MultiQC 1.24.1 mamba In multiqc_env
Nextflow Latest Script (curl) Bootstrap install
NCBI BLAST+ 2.16.0 Binary From NCBI FTP
RepeatMasker 4.1.7-p1 Source Requires local famdb setup
salmon 1.10.0 Binary From GitHub release
samtools 1.20 Source Compiled locally
StringTie 2.2.1 Binary From StringTie website
Trimmomatic 0.39 Binary (Java-based) Made executable

2.2 Leveraging the ckpt Partition

Tip

If your job will run for less than 5 hours, use the ckpt partition. These are unused shared UW-wide resources and won’t count against your group allocation. However, jobs may be preempted after 5 hours.

## Selecting Resources

After selecting RStudio, you’ll be prompted to specify the computing resources needed.

![Resource Selection](http://gannet.fish.washington.edu/seashell/snaps/Monosnap_RStudio_-_Hyak_OnDemand_2025-05-01_12-04-18.png){width=70%}

If you're unfamiliar with the Klone cluster, it’s helpful to explore your resource allocations:

1. Click on `>_ Klone Login` from the dashboard.
2. Enter your UW credentials.
3. Run the `hyakalloc` command:

```bash
hyakalloc
```

This will display your available and used CPU/memory allocations.

### Leveraging the `ckpt` Partition

::: {.callout-tip}
If your job will run for **less than 5 hours**, use the `ckpt` partition. These are unused shared UW-wide resources and won't count against your group allocation. However, jobs **may be preempted** after 5 hours.
:::
